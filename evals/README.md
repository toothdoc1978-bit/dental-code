# Eval harness

A scored, regression-safe loop for improving note quality without "training" the
model. The model weights never change — instead you grow a set of cases and a
compliance rubric, measure a pass-rate, and drive it up by refining the system
prompt / deterministic blocks in `server/noteGenerator.js`.

## What's here

- `schema.mjs` — chart-data shape + `cleanChart()` (strips anything outside the
  allow-list, so generated/loaded charts can never carry PHI).
- `rubric.mjs` — self-gating compliance checks (SOAP structure, no fabrication,
  ALARA rationale, consent fork, post-op + closing block, medical necessity,
  EPSDT caries risk, pediatric visual perio, etc.). Each returns pass/fail/warn/na.
- `cases.mjs` — hand-written **seed cases** pinning the behaviors we built. This
  is the regression core — keep it green.
- `generate.mjs` — asks Claude for diverse, PHI-free synthetic encounters to add
  breadth. Writes `generated/cases-<ts>.json`.
- `run.mjs` — generates a note per case, scores it, prints a dashboard, and
  writes `report.md` / `report.json`. Exits non-zero on any failure (CI-gateable).

## Usage

```bash
# 1. Run the regression core (notes via local generateNote)
ANTHROPIC_API_KEY=... node evals/run.mjs --seed-only

# 2. Generate synthetic breadth, then run everything
ANTHROPIC_API_KEY=... node evals/generate.mjs 20
ANTHROPIC_API_KEY=... node evals/run.mjs

# Or score the deployed API instead of local code:
EVAL_URL=https://dental-code.vercel.app/api/generate-note node evals/run.mjs
```

npm scripts: `npm run eval`, `npm run eval:seed`, `npm run eval:generate`.

## The improvement loop

1. `eval:generate` to add diverse cases (or hand-add a case that reproduces a
   real weakness you spotted).
2. `eval` to get the pass-rate and the list of failing checks.
3. Fix the root cause in `server/noteGenerator.js` (a prompt rule, a deterministic
   block, or a new few-shot example) — not by special-casing the test.
4. Re-run. The seed cases guard against regressing a past win.

## Trust note

Synthetic cases are generated by the same model family that writes the notes, so
they share blind spots. The rubric is deterministic (it doesn't ask a model to
grade), which mitigates this — but periodically review a sample of generated
notes yourself. Your clinical judgment is the ground truth the loop can't supply.
